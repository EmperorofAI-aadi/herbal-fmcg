# 🌿 PrakritiGlow — 100% Herbal & Chemical-Free Website

Premium React website for a herbal FMCG brand. Products: hand wash, dish wash, shampoo, hair oil, balm, cream, moisturiser.

## ✨ Features
- Stunning animated hero section (device-independent — works on mobile & laptop)
- 7 products with prices, categories & detail popup
- Compare table (herbal vs chemical products)
- Enquiry form, FAQ accordion, contact cards
- Smooth animations, scroll-reveal, floating leaves

## 🚀 How to Run (Beginner Friendly)

```bash
# 1. Install Node.js from https://nodejs.org (LTS version)
# 2. Open this folder in terminal & run:
npm install
npm run dev
```
Then open: **http://localhost:5173**

Windows users can also double-click `START-WEBSITE.bat`.

## 📁 Structure
```
src/
├── data/site.js        → change phone/address WhatsApp here
├── data/products.js    → products & prices here
├── pages/              → Home, Products, About, Contact
├── components/         → Navbar, Footer, ProductCard, etc.
└── index.css           → full design (colors in :root)
```

## 🛠️ Tech
React 18 • React Router 6 • Vite 5 • Custom CSS (no libraries)
